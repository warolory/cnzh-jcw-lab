# cnzh-jcw-lab

## 项目简介

这是一个用于归档和发布多个独立 HTML 页面的仓库。本仓库不针对任何特定域名或具体网站，仅作为静态 HTML 内容的集中存储与展示空间。所收录的页面均为独立的 HTML 文件，可用于演示、存档或轻量级信息呈现。

## 目录说明

```
/
├── index.html          # 仓库入口页面（可选）
├── pages/              # 独立 HTML 页面存放目录
│   ├── example1.html
│   ├── example2.html
│   └── ...
├── assets/             # 公共资源文件（样式、脚本、图片等）
│   ├── css/
│   ├── js/
│   └── images/
└── README.md           # 本文件
```

- **pages/**：存放所有独立 HTML 页面的主目录，每个页面为一个独立的 HTML 文件。
- **assets/**：存放页面共享的静态资源，包括 CSS 样式文件、JavaScript 脚本、图片等。
- **index.html**：仓库根目录下的入口文件（可选），可提供页面导航或索引功能。

## 页面归档说明

本仓库收录的 HTML 页面均为作者自行编写或整理的独立内容。每个页面均保持其原始结构与设计，不附加任何外部追踪、广告或第三方服务。页面内容可能涉及技术演示、学习笔记、工具页面或静态信息展示等，但均不指向任何具体商业或营销目的。

如需添加新页面，请遵循以下原则：

- 页面应保持独立，不依赖仓库外部的资源（除非必要）。
- 页面命名应简洁明了，体现内容主题。
- 如需引用公共资源，请统一放置于 `assets/` 目录下。
